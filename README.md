# LIVE POCKET — イベント・チケット管理

サイトで自分の名前を選び、参戦予定・整理番号・余りチケットを管理します。キーやパスワードの発行は不要です。

## 最初の設定

**幹事が1回だけ設定します。メンバーは公開したURLを開くだけです。**

### 1. Google Apps Scriptを開く

[Google Apps Script](https://script.google.com/home/start)を開き、Googleアカウントで「新しいプロジェクト」を作成します。プロジェクト名は「チケット管理」などでOKです。

### 2. 2つのファイルを貼り付ける

| Apps Script側のファイル | 貼り付ける内容 |
|---|---|
| 最初からある「コード.gs」（Code.gsでも可） | [Code.gs](Code.gs)の全文 |
| 左の「＋」→「HTML」で作る「Index」 | [Index.html](Index.html)の全文 |

GitHubの各ファイルを開き、Raw表示かコピー機能で全文をコピーしてください。最初から入っている内容は置き換えて保存します。HTMLの名前は大文字の **Index** にしてください。

**実行ボタン・キー発行・スプシの手動作成は不要です。** `appsscript.json`は通常変更しなくて大丈夫です。

### 3. Webアプリとして公開する

右上の「デプロイ」→「新しいデプロイ」を選びます。

- 種類：歯車から **ウェブアプリ**
- 次のユーザーとして実行：**自分**
- アクセスできるユーザー：**全員**（アカウントの制限により選べない場合があります）

「デプロイ」を押し、自分が作成したこのスクリプトのGoogle権限を確認・許可します。発行された **ウェブアプリのURL（末尾が `/exec`）** を開きます。

初回表示時に、管理スプシ「LIVE POCKET 管理」が自分のGoogleドライブに自動作成されます。Google側の権限確認は省略できません。

### 4. 名前を登録して使い始める

1. 「自分の名前を追加」に呼び名を入力。
2. 「名前を登録して始める」を押す。
3. 「イベント登録」でイベントを追加。
4. 同じWebアプリURLを仲間に共有。

メンバーは一覧から自分の名前を選びます。まだない名前はサイト内で追加できます。選択した名前はこのブラウザに記憶し、右上の「名前を変更」で切り替えます。同名は登録できないので、必要なら「ゆうき（A班）」のように区別してください。

## 更新する時

Apps Scriptの2つのファイルをGitHubの最新版に置き換えて保存し、「デプロイ」→「デプロイを管理」→編集（鉛筆）→バージョン「新バージョン」→「デプロイ」と進みます。既存のURLを引き続き使用できます。

旧キー方式から更新しても、既存メンバー・イベント・チケットは残ります。名前は既存の一覧から選べます。追加のイベント列は自動で用意します。Membersシートの旧tokenHash列は互換性のため残りますが、現在は使いません。

## イベント登録

日付・イベント名・会場・チケット購入ページURL・抽選締切・必要投げ数（1人あたり）の順で入力します。日付とイベント名は必須です。

続けて **出演グループを複数選択** できます。新しいグループはその場で追加し、イベントを保存すると登録済みイベントのグループが次回の選択肢に表示されます。カンマ・読点で区切って複数入力できます。最大20組、各40文字。全イベントから外れたグループは選択肢にも表示されなくなります。

グループはイベントタイルと詳細にタグ表示し、トップの検索でも探せます。関連スプシURLとメモは折りたたみ欄から登録します。

## チケット登録

イベントを選び「自分の番号を登録」から、整理番号を改行・空白・カンマでまとめて入力します。登録中に枚数を表示します。未発券なら番号の代わりに枚数だけ登録できます。

- 状態：未発券／自分用／余り／取引中／捌けた
- 1枚ごとの譲り先・メモ
- 選択中の名前に紐づくチケットを編集・削除
- 全員の参戦予定・余り枚数を確認
- 重複番号の拒否、同時更新の衝突検出

## トップのタイルと順序

日付・イベント名・会場・出演グループを表示します。

| 日本時間での表示期間 | 追加情報 |
|---|---|
| 抽選締切当日まで | 抽選締切・必要投げ数（1人あたり）・チケットURL |
| 抽選締切翌日から | 全体あまり数・関連スプシURL |

締切未設定は申込情報を表示します。全体あまり数は「余り」状態のみの合計で、自分用・取引中・捌けた・未発券は含みません。

並び順は **開催当日→抽選締切当日→抽選締切前日→その他の開催日順**。同じ優先順位内も開催日順です。過去のイベントもその他に含めます。

## 仲間内での利用について

**名前の選択は本人確認ではありません。URLを知っている人は名前一覧を見たり、名前を追加したり、ほかの人の名前を選んでその人の情報を編集できます。** 仲間内でURLを共有する使い方です。名前選択をセキュリティ上のアクセス制限としては使えません。

管理スプシ自体をメンバーに共有する必要はありません。メンバーの使用を止めるときは管理者がMembersシートのactiveをyes以外に変更できます。関連スプシURLはリンクとして保存するだけで、そのスプシ内のデータを自動取込するものではありません。

## 開発・確認

ソースはGitHub、Webアプリ実行はGoogle Apps Script、保存先はスプシです。GitHub Pagesで公開する構成ではありません。

- `node tests/backend.cjs`：名前登録・選択・重複名・グループ・イベント・チケット・旧版データ移行の確認。
- `node tests/tiles.cjs`：タイル切替・日本時間・優先順位・タグのエスケープの確認。
- スマホ用の大きな操作ボタン、画面下の番号登録、固定された保存ボタン、入力破棄確認、保存失敗時の入力保持に対応。

上記のテストは模擬データで実施しています。Googleの実スプシ接続、スマホ実機の描画・操作、公開は未確認です。
